Dson：AI友好的API文档

1. 概述

Dson 是一个Java库，用于将Java对象序列化为类JSON格式的字符串，以及将字符串反序列化回Java对象。 它提供两种操作模式：

  • 标准模式： 使用反射进行序列化/反序列化。这种模式易于使用，无需特殊设置。
  • 编译模式： 对于性能敏感的应用程序，Dson可以在运行时动态生成和编译Java字节码来执行转换。这避免了反射的开销，从而显著提高速度。

2. 基本用法

所有操作的主要入口点是 Dson 类，它提供了一组静态方法以方便使用。

2.1 序列化

要将Java对象转换为Dson字符串，请使用 toJson() 或 toJsonByCompile() 方法。

// Person.java
public class Person {
    private String name;
    private int age;
    // getters and setters...
}

Person person = new Person("张三", 30);

// 使用标准的、基于反射的序列化
String dsonString = Dson.toJson(person);
// 输出: {"name":"张三","age":30}

// 使用性能优化的、基于编译的序列化
String compiledDsonString = Dson.toJsonByCompile(person);
// 输出: {"name":"张三","age":30}

2.2 反序列化

要将Dson字符串转换回Java对象，请使用 fromString() 或 fromStringByCompile() 方法。

String dsonString = "{"name":"李四","age":28}";

// 使用标准的、基于反射的反序列化
Person person = Dson.fromString(Person.class, dsonString);

// 使用性能优化的、基于编译的反序列化
Person personCompiled = Dson.fromStringByCompile(Person.class, dsonString);

// 如果不指定类型，Dson会将其反序列化为Map/List结构
Object genericObject = Dson.fromString(dsonString);
// genericObject 是一个 Map<String, Object>

3. 配置

可以使用 DsonConfig 类来调整Dson的行为。这对于启用编译模式尤为重要。 

// 创建一个配置对象，同时为序列化（写）和反序列化（读）启用编译模式
DsonConfig config = new DsonConfig()
        .setWriteUseCompile(true)
        .setReadUseCompile(true);

// 使用此自定义配置创建一个上下文
DsonContext context = new DsonContext(config);

// 现在使用此上下文进行操作
String dsonString = context.toJson(person);
Person newPerson = context.fromString(Person.class, dsonString);

主要的配置项包括：

  • setWriteUseCompile(boolean): 如果为true，则为序列化过程生成字节码。
  • setReadUseCompile(boolean): 如果为true，则为反序列化过程生成字节码。

4. 自定义转换器

Dson允许您通过实现 TypeWriter 和 TypeReader 接口，为特定类型定义自定义的序列化和反序列化逻辑。

4.1 自定义序列化 (TypeWriter)

实现 TypeWriter 接口来控制一个类型如何被转换为字符串。

// 示例：一个将 java.util.Date 序列化为时间戳的自定义写入器
public class CustomDateWriter implements TypeWriter {
    @Override
    public void toJson(Object entity, StringBuilder output) {
        Date date = (Date) entity;
        output.append(date.getTime());
    }
}

// 此自定义写入器可以注册到DsonContext中，
// 或通过 @SerializeDefinition 注解直接在字段上指定。

4.2 自定义反序列化 (TypeReader)

实现 TypeReader 接口来控制一个字符串如何被转换为对象。

// 示例：一个从时间戳反序列化为 java.util.Date 的自定义读取器
public class CustomDateReader implements TypeReader {
    @Override
    public Object fromString(Stream stream) {
        long timestamp = stream.getLong(); // 假设stream有方法可以读取一个long
        return new Date(timestamp);
    }
}

5. 注解

Dson提供注解，让您可以直接在模型类上控制序列化过程。

5.1 @JsonIgnore

在字段或方法上使用此注解，可将其从序列化和反序列化过程中排除。

public class User {
    private String username;
    
    @JsonIgnore
    private String password; // 此字段将不会被序列化
}

5.2 @JsonRename

使用此注解来更改字段在Dson输出中的名称。

public class Product {
    @JsonRename("product_id")
    private String productId;
    
    private String name;
}

// 序列化Product对象将得到:
// {"product_id":"some-id","name":"A Product"}

5.3 针对字段的转换器

您可以将特定的 TypeWriter 或 TypeReader 直接应用于某个字段，这将覆盖该字段的任何全局注册转换器。这通过 @SerializeDefinition 和 @DeSerializeDefinition 注解完成。

@SerializeDefinition

指定一个 TypeWriter 类，用于序列化特定字段。

// 一个将布尔值序列化为 1 或 0 的自定义写入器
public class BooleanAsIntWriter implements TypeWriter {
    @Override
    public void toJson(Object entity, StringBuilder output) {
        output.append(((Boolean) entity) ? "1" : "0");
    }
}

public class Settings {
    @SerializeDefinition(BooleanAsIntWriter.class)
    private boolean notificationsEnabled; // 将被序列化为 1 或 0
    
    private String theme;
}

@DeSerializeDefinition

指定一个 TypeReader 类，用于反序列化特定字段。

// 一个将 1 或 0 反序列化为布尔值的自定义读取器
public class BooleanAsIntReader implements TypeReader {
    @Override
    public Object fromString(Stream stream) {
        return stream.getInt() == 1; // 简化示例
    }
}

public class Settings {
    @DeSerializeDefinition(BooleanAsIntReader.class)
    private boolean notificationsEnabled; // 可以从 1 或 0 进行反序列化
    
    private String theme;
}
